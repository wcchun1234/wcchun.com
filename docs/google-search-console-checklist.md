# Google Search Console launch checklist

Use this checklist after publishing a portfolio update. The live property should be the domain property for `wcchun.com`.

## One-time setup

- [ ] Confirm ownership of the `wcchun.com` domain property.
- [ ] Confirm both `https://wcchun.com` and `https://www.wcchun.com` resolve consistently.
- [ ] Submit `https://wcchun.com/sitemap.xml` under **Sitemaps**.
- [ ] Check that `https://wcchun.com/robots.txt` is reachable.

## Request indexing for current pages

- [ ] Inspect and request indexing for `https://wcchun.com/`.
- [ ] Inspect and request indexing for each `/work/` project page.
- [ ] Inspect and request indexing for each `/technology/` case-study page.
- [ ] Confirm Google selects the same canonical URL declared by the website.

## Retire old Google Sites results

- [ ] Inspect `/home` and confirm it points visitors to the current homepage.
- [ ] Inspect old ArtSense and photography URLs and confirm their canonical destinations.
- [ ] Use **Removals** only for obsolete results that must disappear urgently; removal is temporary and does not replace canonical or redirect signals.
- [ ] Recheck search results after Google recrawls the affected URLs.

## Ongoing checks

- [ ] Review **Page indexing** for new errors after each launch.
- [ ] Review **Core Web Vitals** on mobile and desktop.
- [ ] Check **HTTPS** and **Manual actions**.
- [ ] Review search queries for “Wong Chun”, “Sunny Wong”, “WCCHUN” and key project names.
- [ ] Resubmit the sitemap only when troubleshooting; Google discovers routine updates automatically.
